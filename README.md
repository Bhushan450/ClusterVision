# Wholesale Customer Segmentation and Purchasing Analytics

A college Machine Learning Mini Project using unsupervised clustering algorithms (K-Means, K-Medoids/PAM, and DBSCAN) to discover wholesale client purchasing groups and behavioral patterns from the UCI Wholesale Customers dataset.

---

## Features

- **Automated Data Pipeline & Quality Checks**: Preprocessing, categorical filtering, missing value handling, and feature scaling using `StandardScaler`.
- **Multi-Algorithm Clustering**:
  - **K-Means**: Centroid-based partitioning minimizing intra-cluster variance.
  - **K-Medoids (PAM)**: Pure Python/NumPy medoid-based partitioning for superior outlier resistance.
  - **DBSCAN**: Density-based clustering for discovering arbitrary shapes and auto-detecting noise points.
- **Dimensionality Reduction**: Principal Component Analysis (PCA) 2D projection for clear visual cluster separation when multiple features are selected.
- **Cluster Validation**: Silhouette score evaluation across all algorithms.
- **Interactive Streamlit Dashboard**: Dynamic algorithm switching, hyperparameter sliders ($K$, $\epsilon$, `min_samples`), feature selection, and downloadable CSV reports per segment.
- **Custom CSV Upload**: Support for uploading external compatible customer spending datasets.

---

## Dataset

The default dataset is the **UCI Wholesale Customers Dataset** (440 clients; attributes represent annual spending in monetary units across product categories):
- Categorical Attributes: `Channel` (HORECA/Retail), `Region`
- Continuous Spending Attributes: `Fresh`, `Milk`, `Grocery`, `Frozen`, `Detergents_Paper`, `Delicassen`

- **Dataset Source**: [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/machine-learning-databases/00292/Wholesale%20customers%20data.csv)
- **Dataset Behavior**: The app automatically fetches the dataset directly from the UCI repository. If offline, users can upload `Wholesale_customers_data.csv` via the Streamlit interface or place it in the root directory.

> **Dataset Limitation**: This dataset reflects aggregate annual spending across product categories rather than real-time transactional logs. Marketing and supply chain recommendations are illustrative hypotheses based on segment spending profiles.

Methods & Techniques
Preprocessing: StandardScaler feature normalization

Algorithms:

K-Means Clustering (sklearn.cluster.KMeans)

Pure K-Medoids / PAM (PureKMedoids custom NumPy implementation for Python 3.14 compatibility)

DBSCAN (sklearn.cluster.DBSCAN)

Dimensionality Reduction: Principal Component Analysis (sklearn.decomposition.PCA)

Validation Metric: Silhouette Score (sklearn.metrics.silhouette_score)

Local Setup & Execution
1. Install Dependencies
Ensure you have Python installed (Python 3.10 to 3.14 supported). Run:

Bash
pip install -r requirements.txt
2. Run Standalone Script
To execute model training, print console metrics, and generate clustered_wholesale_customers.csv:

Bash
python wholesale_clustering.py
3. Launch Streamlit Dashboard
To run the interactive web application:

Bash
streamlit run app.py
Then open the local URL shown in your terminal (typically http://localhost:8501).

Deploy on Streamlit Community Cloud
Push all files (app.py, requirements.txt, README.md) to a GitHub repository.

Visit share.streamlit.io and log in with GitHub.

Connect your repository, set the main file path to app.py, and click Deploy.

Important Evaluation Note
Do not report an accuracy score for this project. Clustering is an unsupervised learning method, meaning ground-truth class labels do not exist. Standard classification accuracy is not applicable. Model quality is evaluated using the Silhouette Score, cluster density, and segment spending profile interpretations generated by the app.
